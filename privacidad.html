Política de privacidad

Última actualización: 24 de noviembre de 2026.

canales-ops es una herramienta privada que usa únicamente el dueño de los canales de YouTube Jaragua Gecko y La Séptima Sala para subir, programar y administrar sus propios videos.

Qué datos usa

Con el permiso que el dueño da mediante Google OAuth, la herramienta accede a la API de YouTube Data para: subir videos y miniaturas, editar títulos, descripciones y privacidad, borrar videos propios y leer estadísticas de sus propios canales.

Cómo se guardan

El permiso (token de OAuth) se guarda sólo en la computadora del dueño, con acceso restringido. No se guarda en servidores de terceros ni en repositorios de código.

Con quién se comparten

Con nadie. No se venden, no se ceden y no se usan para publicidad. No se recogen datos de otras personas.

Cómo revocar el acceso

El dueño puede quitar el permiso cuando quiera en myaccount.google.com/permissions.

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. La herramienta usa los Servicios de API de YouTube; ver también las Condiciones de YouTube y la Política de privacidad de Google.
